Connect your Ifallhub engine

This web interface uses your local streaming service to find titles and prepare playback. Start the API locally, then launch the web app with its API URL.

Terminal 1 · Rust APIcargo run -- --web-api
Terminal 2 · Web UIIFALLHUB_API_URL=http://127.0.0.1:8787 npm run dev
i

The API binds to 127.0.0.1 by default so it stays on your device. The demo preview uses sample titles and a public sample clip.
